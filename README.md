# Teoría de sistemas operativos

## Bloque 1.1: introducción a los sistemas operativos

Esta guía transforma las diapositivas en apuntes ordenados y estudiables.

### Objetivo del bloque

Reconocer los componentes de un sistema informático.

Comprender cómo el sistema operativo administra el equipo.

Relacionar redes, interfaces, licencias y distribuciones con su uso real.

{% hint style="info" %}
Estudia cada apartado en orden.\
Termina con la página de resumen y autoevaluación.
{% endhint %}

### Método recomendado

1. Lee una página y repite sus ideas clave.
2. Dibuja sus esquemas sin mirar los apuntes.
3. Responde las preguntas antes de consultar soluciones.

### Qué vas a dominar

* Representación y tratamiento de la información.
* Componentes y arquitectura de un ordenador.
* Funciones y tipos de sistemas operativos.
* Fundamentos de red e interfaces de usuario.
* Licencias, distribuciones y compatibilidad de software.
