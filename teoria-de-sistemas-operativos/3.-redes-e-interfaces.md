# 3. Redes e interfaces

## Redes e interfaces

### Objetivo

Identificar los elementos básicos de una red y las formas de interactuar con un sistema.

### Cómo viajan los datos

Las redes transmiten bits mediante señales físicas.

Pueden usar:

* Pulsos eléctricos.
* Ondas de radio o frecuencias.
* Pulsos de luz.
* Pulsos mecánicos.

El medio cambia, pero el objetivo es el mismo.

El receptor debe reconstruir los datos enviados.

### Direccionamiento básico

| Elemento      | Qué identifica                   | Ejemplo             |
| ------------- | -------------------------------- | ------------------- |
| Dirección IP  | Un equipo dentro de una red.     | `192.168.1.20`      |
| Máscara       | La parte de red y de host.       | `255.255.255.0`     |
| Dirección MAC | Una interfaz de red física.      | `00:1A:2B:3C:4D:5E` |
| Hostname      | El nombre local del equipo.      | `equipo-aula`       |
| Dominio       | Un nombre traducible a una IP.   | `ejemplo.com`       |
| VPN           | Un túnel cifrado hacia otra red. | Acceso remoto.      |

La IP es una dirección lógica.

La MAC identifica la interfaz en la red local.

La MAC pertenece a la capa de enlace de datos.

Una IP dinámica se asigna temporalmente, normalmente con DHCP.

### Modelos de red

El modelo OSI divide la comunicación en siete capas.

El modelo TCP/IP las agrupa en cuatro.

| TCP/IP       | Capas OSI relacionadas             |
| ------------ | ---------------------------------- |
| Aplicación   | Aplicación, presentación y sesión. |
| Transporte   | Transporte.                        |
| Internet     | Red.                               |
| Acceso a red | Enlace de datos y física.          |

La capa física transmite señales.

La capa de enlace usa tramas y direcciones MAC.

La capa de red usa direcciones IP y enrutamiento.

### Interfaces de usuario

Una interfaz permite comunicarse con el sistema operativo.

| Característica      | GUI                               | CLI                         |
| ------------------- | --------------------------------- | --------------------------- |
| Interacción         | Ventanas, iconos y menús.         | Comandos escritos.          |
| Dispositivos        | Ratón, teclado o pantalla táctil. | Principalmente teclado.     |
| Aprendizaje inicial | Más accesible.                    | Requiere aprender comandos. |
| Automatización      | Menor.                            | Alta mediante scripts.      |
| Recursos            | Suele consumir más.               | Suele consumir menos.       |

La **GUI** facilita tareas visuales.

La **CLI** ofrece precisión y automatización.

No son alternativas excluyentes.

### Ideas clave

* Las IP identifican equipos de forma lógica.
* Las MAC identifican interfaces dentro de la red local.
* OSI ayuda a separar responsabilidades.
* GUI y CLI responden a necesidades distintas.
