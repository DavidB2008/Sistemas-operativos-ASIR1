# Resumen y autoevaluación

## Resumen y autoevaluación

### Mapa del bloque

```
Sistema informático
├── Información
│   ├── Datos
│   ├── Codificación
│   └── Entrada → proceso → salida
├── Componentes
│   ├── Hardware
│   ├── Software
│   └── Personas
├── Sistemas operativos
│   ├── Kernel
│   ├── Procesos
│   ├── Memoria
│   └── Entrada y salida
├── Redes
│   ├── IP, máscara y dominio
│   ├── MAC
│   └── OSI y TCP/IP
└── Software
    ├── Licencias
    ├── Distribuciones
    └── Actualizaciones y drivers
```

### Diez ideas esenciales

1. Los datos se convierten en información al procesarse.
2. Todo dato digital se representa mediante bits.
3. Un byte contiene 8 bits.
4. Un sistema combina hardware, software y personas.
5. La unidad de control coordina la ejecución.
6. Un sistema operativo administra los recursos.
7. El kernel se comunica directamente con el hardware.
8. IP y MAC identifican elementos diferentes.
9. GUI y CLI son interfaces complementarias.
10. Las licencias definen los permisos sobre el software.
