# 4. Software, licencias y distribuciones

## Software, licencias y distribuciones

### Objetivo

Distinguir modelos de licencia y administrar software de forma segura.

### Licencias y derechos

Una licencia define qué se puede hacer con una obra.

| Modelo               | Idea principal                                          |
| -------------------- | ------------------------------------------------------- |
| Copyright            | El autor conserva los derechos.                         |
| Creative Commons     | Licencias habituales para contenidos.                   |
| Dominio público      | La obra no tiene restricciones de copyright aplicables. |
| Software libre       | Garantiza libertades sobre el programa.                 |
| Software propietario | Limita acceso, modificación o redistribución.           |

El software libre no significa necesariamente software gratuito.

Sus libertades se centran en usar, estudiar, modificar y compartir.

El código fuente debe estar disponible para estudiar y modificar.

### Distribuciones Linux

Una **distribución** combina el kernel Linux con herramientas y repositorios.

También incluye un instalador y un sistema de paquetes.

Ejemplos: Ubuntu, Debian, Fedora, Arch Linux y Alpine Linux.

Cada distribución prioriza necesidades distintas.

| Uso frecuente         | Ejemplos                             |
| --------------------- | ------------------------------------ |
| Escritorio            | Ubuntu y Linux Mint.                 |
| Servidor              | Debian, Rocky Linux y Ubuntu Server. |
| Ligero o contenedores | Alpine Linux.                        |
| Aprendizaje avanzado  | Arch Linux.                          |

### Instalar y actualizar software

Prioriza los repositorios oficiales de tu distribución.

Después usa su gestor gráfico o su gestor de paquetes.

Descargar programas de Internet requiere más comprobaciones.

En sistemas basados en Debian o Ubuntu:

```bash
sudo apt update
sudo apt upgrade
```

`apt update` actualiza la lista de paquetes.

`apt upgrade` instala versiones disponibles.

{% hint style="warning" %}
Revisa el origen y la versión antes de instalar software externo.
{% endhint %}

Las actualizaciones pueden ser:

* De seguridad.
* Recomendadas o de mantenimiento.
* Previas, para pruebas.
* No soportadas o fuera de mantenimiento.

### Controladores y compatibilidad

Un **driver** permite que el sistema operativo use un dispositivo.

La compatibilidad depende del fabricante, el kernel y la distribución.

Antes de instalar Linux, verifica:

* Tarjeta gráfica y red.
* Almacenamiento y firmware.
* Arquitectura del procesador.
* Soporte de la distribución elegida.

Windows y Linux responden a modelos diferentes.

La elección depende del hardware, las aplicaciones y los conocimientos disponibles.

### Ideas clave

* Una licencia establece permisos y límites.
* Linux se distribuye mediante proyectos diferentes.
* Los repositorios reducen riesgos de instalación.
* Los drivers determinan la compatibilidad del hardware.
