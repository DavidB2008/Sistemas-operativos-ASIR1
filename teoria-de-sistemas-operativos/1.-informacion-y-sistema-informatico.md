# 1. Información y sistema informático

## Información y sistema informático

### Objetivo

Distinguir datos, información y los elementos de un sistema informático.

### De los datos al conocimiento

Un **dato** describe un hecho sin interpretar.

La **información** surge al ordenar y procesar datos.

`datos → tratamiento → información → conocimiento`

Los datos pueden ser:

* **Numéricos:** `0` a `9`.
* **Alfabéticos:** letras.
* **Alfanuméricos:** letras, números y símbolos.

### Representación digital

Un ordenador representa cualquier dato mediante bits.

Un **bit** puede valer `0` o `1`.

Un **byte** contiene 8 bits.

Un byte permite `2^8 = 256` combinaciones.

| Unidad decimal | Equivalencia | Unidad binaria | Equivalencia |
| -------------- | -----------: | -------------- | -----------: |
| kB             |    10³ bytes | KiB            |    2¹⁰ bytes |
| MB             |    10⁶ bytes | MiB            |    2²⁰ bytes |
| GB             |    10⁹ bytes | GiB            |    2³⁰ bytes |
| TB             |   10¹² bytes | TiB            |    2⁴⁰ bytes |

{% hint style="info" %}
`kB` y `KiB` no representan exactamente la misma cantidad.
{% endhint %}

### Sistemas de numeración y codificación

| Sistema     | Base | Relación con el binario       |
| ----------- | ---: | ----------------------------- |
| Binario     |    2 | Cada cifra es `0` o `1`.      |
| Octal       |    8 | Cada cifra representa 3 bits. |
| Hexadecimal |   16 | Cada cifra representa 4 bits. |

Hexadecimal usa `0–9` y `A–F`.

Se usa porque resume cadenas binarias largas.

Para texto, se usan codificaciones de caracteres:

* **ASCII:** 7 bits y 128 símbolos.
* **ASCII extendido:** nombre genérico para páginas de 8 bits.
* **Unicode:** repertorio universal de caracteres.
* **UTF-8, UTF-16 y UTF-32:** formas de codificar Unicode.

### Tratamiento de la información

El tratamiento sigue tres fases:

`entrada → proceso → salida`

| Fase    | Función                                   |
| ------- | ----------------------------------------- |
| Entrada | Recoge, valida y almacena datos.          |
| Proceso | Aplica operaciones aritméticas y lógicas. |
| Salida  | Presenta y distribuye resultados.         |

### Sistema informático

Un sistema informático combina tres elementos:

`hardware + software + personas`

| Elemento | Función                                     | Ejemplos                          |
| -------- | ------------------------------------------- | --------------------------------- |
| Hardware | Parte física.                               | CPU, teclado, disco y monitor.    |
| Software | Parte lógica.                               | Sistema operativo y aplicaciones. |
| Personas | Usan, administran o desarrollan el sistema. | Usuarios y personal técnico.      |

El **software básico** permite funcionar al equipo.

El **software de aplicación** resuelve tareas concretas.

Un **programa** contiene instrucciones ordenadas.

Una **aplicación** reúne uno o varios programas para un usuario.

### Arquitectura de Von Neumann

Un ordenador clásico integra cuatro bloques:

`entrada → CPU ↔ memoria → salida`

La CPU incluye:

* **Unidad de control:** interpreta instrucciones y coordina operaciones.
* **ALU:** realiza operaciones aritméticas y lógicas.

La memoria guarda datos e instrucciones.

Los periféricos conectan el sistema con el exterior.

| Tipo    | Ejemplos                                     |
| ------- | -------------------------------------------- |
| Entrada | Teclado, ratón, cámara y micrófono.          |
| Salida  | Monitor, impresora, altavoces y auriculares. |

### Ideas clave

* La información resulta de procesar datos.
* Todo dato digital se representa con bits.
* Hardware, software y personas forman un sistema informático.
* La CPU procesa instrucciones y la memoria las conserva.
