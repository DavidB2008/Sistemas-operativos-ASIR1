# 2. Sistemas operativos

## Sistemas operativos

### Objetivo

Comprender cómo un sistema operativo coordina el hardware y las aplicaciones.

### Qué es un sistema operativo

Un **sistema operativo** es el software que administra el equipo.

Facilita el uso del ordenador y mejora su eficiencia.

Actúa entre el hardware, las aplicaciones y las personas usuarias.

### Qué gestiona

| Recurso          | Función                                     |
| ---------------- | ------------------------------------------- |
| Procesador       | Decide qué proceso ejecuta la CPU.          |
| Memoria          | Reserva y libera memoria para los procesos. |
| Entrada y salida | Coordina periféricos y controladores.       |
| Archivos         | Organiza datos en sistemas de ficheros.     |

Un sistema operativo moderno debe:

* Ejecutar varios procesos de forma coordinada.
* Asignar recursos sin provocar interbloqueos.
* Permitir comunicación fiable entre procesos.
* Evolucionar mediante componentes modulares.
* Facilitar el uso compartido de recursos.

### Tipos de sistemas operativos

| Criterio      | Tipos principales                                    |
| ------------- | ---------------------------------------------------- |
| Estructura    | Monolítico, micronúcleo e híbrido.                   |
| Dispositivo   | Escritorio, servidor, móvil, embebido y tiempo real. |
| Servicios     | Monousuario, multiusuario, monotarea y multitarea.   |
| Procesadores  | Uniproceso y multiproceso.                           |
| Procesamiento | Centralizado, distribuido, de red y clúster.         |

Un núcleo **monolítico** concentra muchos servicios en el espacio de núcleo.

Un **micronúcleo** mantiene solo los servicios esenciales.

Un núcleo **híbrido** combina ambos enfoques.

### Módulos principales

* **Núcleo o kernel:** comunica el software con el hardware.
* **Gestor de procesos:** planifica la ejecución.
* **Gestor de memoria:** asigna memoria a cada proceso.
* **Gestor de entrada/salida:** coordina dispositivos.
* **Gestor de ficheros:** organiza archivos y directorios.

El planificador decide qué proceso recibe tiempo de CPU.

Las interrupciones avisan de eventos importantes.

Ejemplos: una tecla pulsada o una operación de disco terminada.

### Arranque del sistema

El arranque carga el sistema operativo en memoria.

1. El firmware inicia y comprueba el hardware.
2. Selecciona un dispositivo de arranque.
3. Ejecuta el cargador de arranque.
4. El cargador inicia el kernel.
5. El kernel activa controladores y servicios.
6. El sistema presenta la pantalla de inicio.

{% hint style="info" %}
BIOS y MBR describen el arranque clásico.\
Los equipos actuales suelen usar UEFI y una partición EFI.
{% endhint %}

### Ideas clave

* El sistema operativo administra los recursos.
* El kernel es la parte más cercana al hardware.
* La multitarea alterna procesos para aprovechar la CPU.
* El arranque prepara el equipo antes de iniciar sesión.
